# Typography Rule

프로젝트 내 모든 텍스트(UI 요소, 버튼, 라벨, 헤더, 본문, 안내문 등)를 생성하거나 수정할 때, 글씨 크기(Font Size)는 반드시 자연수 $N \in \mathbb{N}$ 에 대하여 **`(0.2N + 0.05)rem`** 크기로 설정합니다.

### 크기 기준표 예시
- $N=4$: `0.85rem` (세부 라벨, 배지, 안내 텍스트, 닉네임 목록 등)
- $N=5$: `1.05rem` (본문, 입력창, 상태 바, 일반 버튼 텍스트, 탭 버튼 등)
- $N=6$: `1.25rem` (서브 헤더, 노드 버튼, 점수판 헤더 등)
- $N=7$: `1.45rem` (메인 조작 버튼, '홈으로' 버튼, 강조 라벨 등)
- $N=8$: `1.65rem` (페이지 타이틀, 주요 입력 라벨, 사이트 이름 등)
- $N=9$: `1.85rem` (카드/박스 헤더, 핵심 액션 버튼 등)
- $N=10$: `2.05rem`
- $N=15$: `3.05rem` (타깃 넘버 등 대형 수치)
- $N=30$: `6.05rem` (카운트다운 숫자 등 특대형 텍스트)
